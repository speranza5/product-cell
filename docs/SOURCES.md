# Fuentes y vigencia

El diseño del proceso surge de las decisiones de esta conversación. Las capacidades de Codex se contrastaron con documentación oficial consultada el 27 de noviembre de 2026.

- [Subagentes y agentes personalizados](https://learn.chatgpt.com/docs/agent-configuration/subagents): delegación, archivos TOML, modelos y permisos heredados.
- [Instrucciones AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md): carga de instrucciones del proyecto.
- [Creación de skills](https://learn.chatgpt.com/docs/build-skills): estructura, referencias y ubicaciones.

Antes de instalar o modificar configuración en otra versión de Codex, comprobar la documentación y la disponibilidad del cliente. Los modelos sugeridos son una política inicial, no garantía de acceso ni de ahorro.

Las instrucciones específicas de Gym Tracker y CEDEAR Tracker aún no fueron incorporadas ni auditadas. E01 establece sus fuentes. Los nombres y campos de los documentos de workflow son convenciones de este proyecto, no una API nativa de Codex.
